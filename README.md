# 会展数字化综合运营管理系统 (ExpoDigitalOps)

> 实现会展活动全流程数字化管理，从前期策划、参展商管理、观众注册、展位分配、现场签到，到数据分析与后期统计。

## 🛠 技术栈

| 层面 | 技术选型 |
|------|---------|
| **前端** | Vue 3 + TypeScript + Ant Design Vue 4 + ECharts + Pinia |
| **后端** | Node.js + Express + TypeScript |
| **数据库** | MySQL 8.0 |
| **ORM** | mysql2 (原生连接池) |
| **认证** | JWT (jsonwebtoken) |
| **部署** | Docker + Docker Compose + Nginx |

## 🚀 启动指南 (How to Run)

1. 确保 **Docker Desktop** 已启动。
2. 在根目录执行：
   ```bash
   docker compose up --build
   ```
3. 等待所有容器启动完成（约 2-3 分钟）...

## 📦 功能模块

| 模块 | 功能描述 |
|------|---------|
| 📊 数据看板 | KPI统计卡片 + ECharts多维图表（趋势、饼图、柱图） |
| 📋 会展项目管理 | 会展 CRUD、状态流转（筹备中→进行中→已结束） |
| 🏢 参展商管理 | 注册、审核（通过/拒绝）、展位关联 |
| 👥 观众管理 | 在线注册、生成唯一票码、电子票查看 |
| 🗺️ 展位管理 | 展位状态可视化、一键分配/取消分配 |
| ✅ 签到管理 | 扫码签到、手动签到、签到统计 |
| 📈 数据统计 | 多维度分析图表、按会展维度统计 |
| 💳 支付管理 | 创建订单、确认收款、退款操作 |
| 📄 合同管理 | 创建合同、电子签署 |
| 🔔 消息通知 | 发送通知、已读/未读管理、分角色推送 |
| 👤 用户管理 | RBAC用户管理、角色分配、密码重置 |
| 📋 操作日志 | 全操作审计记录、模块/结果筛选 |
| 📝 运营待办中心 | 看板汇总待审核参展商/待支付订单/待签署合同/空闲展位，支持一键跳转处理 |
| ⏰ 智能催办 | 支付订单支持催缴与取消，合同支持催签提醒，自动写入消息中心与审计日志 |

## 🔒 安全设计

- JWT Token 认证，24小时有效期
- 基于角色的访问控制（RBAC）：admin / operator / exhibitor / visitor
- 所有删除操作使用 Modal 确认弹窗，防止误操作
